Introduction

Web Technology is used to create and design websites and web pages. HTML (HyperText Markup Language) is the basic language used to create the structure of a webpage. In this lab, we will learn how to create and run HTML webpages using Visual Studio Code (VS Code).

Objectives

  • The main objectives of this lab are:
      To understand the basics of HTML.
      To learn the basic structure of an HTML document.
      To create a simple webpage using VS Code.
      To learn how to use common HTML tags.
      To run and view an HTML webpage in a web browser.
